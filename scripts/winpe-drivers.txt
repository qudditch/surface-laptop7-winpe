# ============================================================================
#  WinPE driver manifest  (one driver-package folder per line)
#  Paths are relative to the Surface driver root, by default:
#      drivers\SurfaceLaptop7\SurfaceUpdate
#
#  Everything listed here is injected into the WinPE boot image (boot.wim)
#  so that the built-in keyboard / touchpad / touchscreen and the internal
#  NVMe disk are usable while PE is running.
#
#  "#" starts a comment.  Lines are ignored, blanks are ignored.
#  You can add extra folders (e.g. a future Surface package) without
#  touching the PowerShell script.
# ============================================================================

# --- Surface input / HID / firmware --------------------------------------
# Surface Laptop 7 (Snapdragon) needs the *Windows PE* build of the Surface
# HID Mini driver (from SurfaceHidMini_WinPE.zip), not the Windows 11 build
# that ships in the MSI's "hidmini" folder.  Do not list "hidmini" here:
# if both are in boot.wim, PnP picks the newer Windows build and the
# keyboard stays dead.  Folder maps to the zip's SurfaceHidMini_WinPE_ARM.
